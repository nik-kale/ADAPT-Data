# ADAPT-Data v0.4.0 - Advanced Features Release

## 🎉 Overview

Version 0.4.0 builds on the production-ready v0.3.0 foundation with **advanced data generation capabilities, intelligent analysis tools, and extensibility features**. This release transforms ADAPT-Data into a sophisticated platform for realistic telemetry generation and analysis.

---

## 🚀 Major New Features

### 1. Progress Indicators ✅
**Location**: `generator/core/progress.py`

**What's New**:
- Rich library integration for beautiful progress bars
- Spinner, bar, and time tracking for long operations
- Automatic fallback to logging if rich unavailable
- Context manager API for easy integration

**Usage**:
```python
from generator.core.progress import get_progress_tracker

tracker = get_progress_tracker()
with tracker.track("Generating metrics", total=1000) as task_id:
    for i in range(1000):
        # Do work
        tracker.update(task_id)
```

**Impact**:
- Better user experience during generation
- Visual feedback for long-running operations
- Professional CLI appearance

---

### 2. Parameterized Distributions ✅
**Location**: `generator/core/distributions.py`

**What's New**:
- 7 probability distributions for realistic data
- Distribution factory for easy configuration
- Predefined distributions for common metrics

**Distributions**:
- `UniformDistribution`: Even distribution
- `NormalDistribution`: Gaussian/bell curve
- `ExponentialDistribution`: Time between events
- `LogNormalDistribution`: Multiplicative processes
- `PoissonDistribution`: Count data
- `WeibullDistribution`: Failure rates
- `BimodalDistribution`: Two peaks

**Configuration Example**:
```yaml
latency_distribution:
  type: lognormal
  mu: 3.5
  sigma: 0.5

error_rate_distribution:
  type: exponential
  rate: 100
```

**Impact**:
- More realistic metric generation
- Configurable variability
- Statistical rigor

### 3. Time-Series Patterns ✅
**Location**: `generator/core/patterns.py`

**What's New**:
- Seasonal patterns (daily, weekly, monthly)
- Trend patterns (linear, exponential)
- Burst patterns (periodic spikes)
- Cyclical patterns (multiple overlapping cycles)
- Noise patterns (realistic randomness)
- Composite patterns (combine multiple patterns)

**Predefined Patterns**:
```python
# Daily pattern with peak at 2pm
create_daily_pattern(amplitude=0.3)

# Weekly pattern (lower weekends)
create_weekly_pattern(amplitude=0.2)

# Business hours pattern
create_business_hours_pattern()

# Growth pattern
create_growth_pattern(rate=0.001)

# Batch job pattern
create_batch_job_pattern()
```

**Example**:
```python
from generator.core.patterns import SeasonalPattern, TrendPattern, CompositePattern

# Combine daily cycle with growth trend
pattern = CompositePattern([
    SeasonalPattern(period_hours=24, amplitude=0.3),
    TrendPattern(trend_type='linear', rate=0.01)
])

# Apply to metric
realistic_value = pattern.apply(base_value=100, timestamp=now)
```

**Impact**:
- Realistic time-series behavior
- Business hours simulation
- Seasonal load variation
- Growth and trend modeling

### 4. Difficulty Levels ✅
**Location**: `generator/core/difficulty.py`

**What's New**:
- 5 difficulty levels for challenges
- Adaptive complexity configuration
- Scoring system with ranks
- Recommendation engine

**Difficulty Levels**:
1. **Beginner**: 3 services, 1 incident, obvious correlations
2. **Easy**: 5 services, 1 incident, clear patterns
3. **Medium**: 8 services, 2 incidents, moderate noise
4. **Hard**: 12 services, 3 incidents, subtle correlations
5. **Expert**: 15 services, 4 incidents, high noise

**Configuration Parameters**:
- `num_services`: Topology complexity
- `num_incidents`: Cascade length
- `noise_level`: Red herrings (0-1)
- `correlation_strength`: How obvious (0-1)
- `hint_availability`: Number of hints
- `time_limit_minutes`: Suggested duration
- `log_volume_multiplier`: Data density
- `metric_density`: Metrics per minute
- `trace_complexity`: Spans per trace

**Scoring Example**:
```python
from generator.core.difficulty import DifficultyLevel, calculate_score

score = calculate_score(
    difficulty=DifficultyLevel.HARD,
    time_taken_minutes=35,
    hints_used=1,
    correct=True
)
# Returns: {'total_score': 440, 'rank': 'Expert', ...}
```

**Impact**:
- Progressive learning paths
- Gamified training
- Skill assessment
- Adaptive challenges

### 5. Configuration File System ✅
**Location**: `generator/core/config.py`

**What's New**:
- `.adapt-data.yaml` configuration files
- Hierarchical config search (current dir → parent → home)
- Environment variable overrides
- Pydantic validation

**Configuration Sections**:
```yaml
logging:
  level: INFO
  enable_colors: true
  log_file: adapt-data.log

generation:
  default_duration: 1h
  default_severity: SEV3
  enable_progress: true
  parallel_generation: false
  random_seed: 42

validation:
  strict_mode: false
  max_scenario_size_mb: 1
  validate_on_generation: true

export:
  default_format: opentelemetry
  prometheus_port: 9090
  replay_speed: 1.0

advanced:
  enable_distributions: true
  enable_patterns: true
  enable_correlation: true
  noise_level: 0.1
```

**Environment Variables**:
- `ADAPT_LOG_LEVEL`: Override log level
- `ADAPT_ENABLE_PROGRESS`: Enable/disable progress
- `ADAPT_OUTPUT_DIR`: Default output directory
- `ADAPT_RANDOM_SEED`: Random seed

**Usage**:
```bash
# Create default config
# (Automatically searches for .adapt-data.yaml)

# Override via environment
export ADAPT_LOG_LEVEL=DEBUG
python -m cli.main generate ...
```

**Impact**:
- Project-specific customization
- Team consistency
- Environment-based configuration
- Better defaults

### 7. Plugin System Framework ✅
**Location**: `generator/core/plugins.py`

**What's New**:
- Extensible plugin architecture
- Three plugin types: Generators, Exporters, Analyzers
- Auto-discovery from `~/.adapt-data/plugins/`
- Plugin registry with lifecycle management

**Plugin Types**:

**Generator Plugin**:
```python
from generator.core.plugins import GeneratorPlugin

class CustomIncidentGenerator(GeneratorPlugin):
    @property
    def name(self) -> str:
        return "custom_incident"

    @property
    def version(self) -> str:
        return "1.0.0"

    def initialize(self) -> None:
        # Setup
        pass

    def generate(self, context, **kwargs):
        # Generate custom incident
        return {"incident_id": "..."}
```

**Exporter Plugin**:
```python
from generator.core.plugins import ExporterPlugin

class CustomExporter(ExporterPlugin):
    @property
    def name(self) -> str:
        return "my_format"

    def export(self, dataset_dir, output_path, **kwargs):
        # Export to custom format
        pass
```

**Analyzer Plugin**:
```python
from generator.core.plugins import AnalyzerPlugin

class CustomAnalyzer(AnalyzerPlugin):
    @property
    def name(self) -> str:
        return "my_analyzer"

    def analyze(self, dataset_dir):
        # Custom analysis
        return {"results": ...}
```

**Usage**:
```python
from generator.core.plugins import get_plugin_registry

registry = get_plugin_registry()

# Load plugins from directory
registry.load_from_directory(Path("./my_plugins"))

# Use plugin
generator = registry.get_generator("custom_incident")
result = generator.generate(context)
```

**Impact**:
- Extensibility without modifying core
- Community contributions
- Custom formats/generators
- Organization-specific tools

## 🚀 Migration Guide

### From v0.3.0 to v0.4.0:

**No changes required!** v0.4.0 is fully backward compatible.

**Optional Enhancements**:

1. **Add Configuration File**:
   ```bash
   # Create .adapt-data.yaml in your project
   cat > .adapt-data.yaml <<EOF
   generation:
     enable_progress: true
     random_seed: 42

   advanced:
     enable_distributions: true
     enable_patterns: true
   EOF
   ```

2. **Use New Features**:
   ```bash
   # Analyze correlations
   python -m cli.main correlate ./my_dataset

   # Progress indicators work automatically
   python -m cli.main generate --scenario my_scenario --output ./out
   ```

3. **Install Optional Dependencies** (for progress bars):
   ```bash
   pip install "adapt-data[all]"
   # or just rich
   pip install rich>=13.0
   ```
